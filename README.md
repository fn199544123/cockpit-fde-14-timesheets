## 项目工时台账看板解决什么问题？

面向项目管理，围绕“工时登记、人工成本与预算对比”提供可操作的演示系统。当前交付状态：**已完成中台功能验收**。

## 系统架构

```text
浏览器页面 → JavaScript 校验与业务计算 → localStorage
浏览器页面 ← 列表 / 指标 / CSV ← 当前浏览器中的演示记录
```

cockpit 用于 AI 开发过程，不是此系统运行的必需服务。本系统没有因为使用 AI 开发而自动接入运行时大模型。

## 本地运行

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 http://127.0.0.1:8000/index.html 。无需构建或后端依赖，也可直接打开 index.html；建议固定 HTTP 地址，避免浏览器存储来源变化。

## 代码目录

```text
index.html     页面、样式与业务逻辑
smoke-test.py  独立浏览器功能测试
assets/       README 品牌素材
README.md      项目说明
LICENSE        MIT 许可证
```

## 操作与业务规则


单个自包含 `index.html`，无 CDN、无第三方网络请求。演示身份为 douyin，所有编号虚构。

## 访问

- 宿主机本地地址：http://127.0.0.1:8414/index.html （本次已运行并验证 HTTP 200；仅宿主机可访问，不是公网地址）。
- 交付入口：当前目录 `index.html`。可直接用浏览器打开，也可由素材中台接入预览。
- 重启本地服务：在本目录执行 `python3 -m http.server 8414 --bind 127.0.0.1`。当前端口已运行时不需要重复启动。

## 操作与验收复现

1. 首次打开默认有三个项目与三名化名人员。项目总览可新增项目、修改预算；人员汇总可新增人员、修改化名和时薪。
2. 点击“登记工时”，日期保留今天，选择 P-002、化名乙，输入 4 小时并保存。
3. 总成本从 4,640 元增至 5,240 元，P-002 累计成本从 2,640 元增至 3,240 元，对比预算 3,000 元显示红色“超预算 ¥240.00”。
4. 工时明细修改该记录为 2 小时，总成本为 4,940 元，超预算数量回落为 0。刷新浏览器仍保留。
5. 输入 -1、0 或 25 小时均拒绝；同人同日跨项目工时之和不得大于 24，恰好 24 允许保存。工时最多两位小数。
6. 日期、人员、项目筛选影响统计卡片、工时明细和投入汇总。预算状态及超预算数量始终使用全部历史数据，页面有口径说明。
7. 当前页面“导出 CSV”导出对应项目/人员/明细的筛选结果。工时可确认后删除，底部可确认后重置全部演示数据。

## 可重复测试

在项目目录执行：

```bash
python3 smoke-test.py
```

依赖宿主机 Python Playwright 和对应 Chromium。本次使用已有安装，无下载、无注册。脚本自行启用随机回环端口和临时浏览器上下文，关闭时回收，不更改使用者浏览器数据。失败返回非零退出码；`smoke-test-result.json` 记录完成的断言，成功时输出 `status: passed`。28 项实际检查通过；桌面与手机证据分别为 `evidence-desktop.png`、`evidence-mobile.png`。

## 能力边界与待补

- 演示数据·仅当前浏览器保存；localStorage 键为 `development-14-state-v1`。不是多用户后台，无账号鉴权、服务端、审批、同步、硬件或扫码接入。
- 清理浏览器数据会丢失记录；不同浏览器及不同来源地址之间不共享数据。CSV 是导出，不提供导入恢复。
- 时薪按登记时保存，修改人员时薪不会追溯改变历史；修改工时所属人员将采用新人员当前时薪。成本按每笔四舍五入到分再汇总。
- 演示录入只应填写化名；项目名自动生成某企业及虚构编号。未接入真实客户、个人或企业资料。

## 验证范围

发布前在独立导出目录验证启动与入口访问；实际结果随发布回执记录。业务验收状态与代码发布状态分开管理。原有测试记录属于历史开发验证，不代表生产环境验收。
